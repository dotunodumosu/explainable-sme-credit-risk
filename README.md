# Explainable SME Credit Risk

An explainable machine learning framework for predicting
SME loan default and supporting credit-risk decision making.

## Research Objective

This project investigates whether machine learning can
improve SME loan default prediction while maintaining
interpretability, calibration, fairness and practical
usefulness for financial institutions.

## Research Questions

1. Can machine learning improve SME default prediction?
2. Which variables are the strongest predictors?
3. Can SHAP explain individual credit-risk predictions?
4. How should banks balance false approvals and false rejections?
5. Can the model support early-warning credit monitoring?

## Models

- Logistic Regression
- Decision Tree
- Random Forest
- XGBoost
- LightGBM

## Explainability

- SHAP
- Feature importance
- Partial dependence

## Evaluation

- ROC-AUC
- PR-AUC
- Precision
- Recall
- F1
- Brier Score
- Calibration
- KS Statistic

## Important

This project is for research and educational purposes.
It is not a production credit-decision system.
